# فرمانده خاورمیانه

بازی استراتژیک آفلاین روی نقشه خاورمیانه، مقابل ربات‌ها. HTML / JavaScript / Canvas بدون وابستگی.

- بازی آنلاین: GitHub Pages (پوشه `docs`)
- ساخت APK: تب Actions ← Build Android APK ← Run workflow ← خروجی `commander-debug-apk`
- برای مایکت باید APK امضاشده (release) ساخته شود.
